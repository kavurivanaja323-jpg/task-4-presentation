AMAZON SALES DASHBOARD ANALYSIS

Project Overview

This project focuses on analyzing Amazon sales data using Python and Power BI. The project includes data cleaning, preprocessing, visualization, dashboard creation, business insights, and statistical validation to support data-driven decision-making.

---

Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

---

Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Dashboard Development
5. Sales & Customer Insights
6. Hypothesis Testing
7. Business Recommendations

---

Key Insights

- Total revenue reached 32.87M
- More than 50K customer orders were recorded
- Total quantity sold exceeded 150K products
- Multiple product categories contributed significantly to overall revenue
- Discounts significantly impacted sales performance

---

Dashboard Features

- Sales Performance Analysis
- Revenue Trends
- Product Category Analysis
- Customer Region Analysis
- Interactive Filters & KPIs

---

Files Included

- Power BI Dashboard (.pbix)
- Python Notebooks (.ipynb)
- Dataset (.csv)
- PPT Presentation
- Project Documentation

---

Conclusion

The project successfully analyzed Amazon sales trends, customer behavior, and product performance using Python and Power BI. The dashboard and statistical analysis provided meaningful business insights and supported better business decision-making.
